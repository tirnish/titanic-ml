## Установка и загрузка данных

### 1. Установка зависимостей

Создайте виртуальное окружение и установите зависимости проекта:

python -m venv .venv

Для Windows PowerShell активируйте окружение:

.venv\Scripts\Activate.ps1

Затем установите необходимые библиотеки:

pip install -r requirements.txt

### 2. Авторизация в Kaggle

Для загрузки данных с Kaggle необходимо авторизоваться в своей учётной записи Kaggle и настроить доступ к API.

Убедитесь, что kagglehub имеет доступ к вашему аккаунту Kaggle.

python -c "import kagglehub; print(kagglehub.whoami())"

### 3. Загрузка данных

Данные соревнования Titanic загружаются с помощью скрипта:

src/download_data.py

Запустите его из корневой директории проекта:

python src/download_data.py

Скрипт автоматически:

1. Загружает файлы соревнования Titanic с Kaggle.
2. Создаёт директорию `data/raw/`, если она отсутствует.
3. Копирует загруженные файлы в `data/raw/`.

После выполнения структура каталога с данными будет выглядеть следующим образом:

data/
└── raw/
    ├── train.csv
    └── test.csv

Исходные данные не обрабатываются и используются как источник для последующих этапов анализа и построения модели.
