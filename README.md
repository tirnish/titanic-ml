# Titanic — классификация выживших пассажиров

## О проекте

Проект посвящён решению задачи бинарной классификации — прогнозированию выживания пассажиров «Титаника».

Цель проекта - исследовать влияние различных методов предобработки данных на качество моделей и сравнить несколько алгоритмов классификации.

В качестве основной метрики качества используется `accuracy`.

В рамках проекта исследуются следующие модели:

* Logistic Regression
* k-Nearest Neighbors (kNN)
* Support Vector Machine (SVM)
* Random Forest
* Gradient Boosting

Также исследуются различные подходы к предобработке данных, включая заполнение пропусков, масштабирование числовых признаков и логарифмическое преобразование.

## Данные

В качестве исходных данных используется обучающая выборка соревнования Titanic на Kaggle.

Обучающая выборка содержит 891 объект и 11 признаков пассажиров.

Целевая переменная:

* `Survived` - индикатор выживания пассажира.

Основные признаки:

| Признак    | Описание                                       |
| ---------- | ---------------------------------------------- |
| `Pclass`   | Класс обслуживания                             |
| `Sex`      | Пол пассажира                                  |
| `Age`      | Возраст                                        |
| `SibSp`    | Количество братьев, сестёр и супругов на борту |
| `Parch`    | Количество родителей и детей на борту          |
| `Ticket`   | Номер билета                                   |
| `Fare`     | Стоимость проезда                              |
| `Cabin`    | Номер кабины                                   |
| `Embarked` | Порт посадки                                   |

В процессе разведочного анализа были исследованы распределения признаков, пропущенные значения, взаимосвязи между признаками и целевой переменной, а также особенности категориальных и числовых признаков.

## Методология

### 1. Разведочный анализ данных (EDA)

Проведён анализ структуры и качества исходных данных:

* изучены типы и распределения признаков;
* проанализированы пропущенные значения;
* исследованы взаимосвязи признаков с целевой переменной;
* проанализирован дисбаланс классов;
* выявлены особенности распределения числовых признаков.

### 2. Предобработка данных

Предобработка выполняется с использованием `Pipeline` и `ColumnTransformer`.

В зависимости от модели исследовались различные варианты обработки признаков:

* заполнение пропущенных значений;
* масштабирование числовых признаков;
* логарифмическое преобразование отдельных признаков;
* кодирование категориальных признаков;
* исключение признаков, не используемых моделью.

Использование `Pipeline` позволяет объединить предобработку и модель в единый объект и выполнять одинаковые преобразования при обучении и оценке модели.

### 3. Построение моделей и подбор гиперпараметров

На первом этапе была построена baseline-модель.

Затем проведено сравнение нескольких алгоритмов классификации с использованием кросс-валидации.

Для перспективных моделей выполнен подбор гиперпараметров. Качество моделей сравнивалось по метрике `accuracy`.

### 4. Финальная модель

По результатам сравнения была выбрана модель Support Vector Machine (SVM).

Для выбранной модели выполнен подбор гиперпараметров с целью максимизации `accuracy`.

Финальная модель представляет собой единый pipeline, включающий предобработку данных и классификатор.

## Установка

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Для Windows PowerShell активируйте окружение:

```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Загрузка данных

Для загрузки исходных данных используется `src/download_data.py`.

Перед запуском скрипта необходимо настроить доступ к Kaggle API.

Проверить авторизацию можно командой:

```bash
python -c "import kagglehub; print(kagglehub.whoami())"
```

После успешной авторизации запустите:

```bash
python src/download_data.py
```

Скрипт загружает данные соревнования Titanic и сохраняет их в директории:

```text
data/raw/
├── train.csv
└── test.csv
```
